## 3 способа «оживить» аватар в CapCut

### Способ A — Быстрый (15 мин, без lip-sync)
1. Кадр аватара + **Плавный зум** 100→108%
2. Озвучка «Текст в речь» поверх
3. Работает для образовательного контента — зрители привыкли к voice-over

### Способ B — CapCut «Цифровой человек» / AI Avatar (если доступно)
1. CapCut → **Цифровой человек** / **AI Avatar**
2. Выберите мужской аватар, близкий по типу (тёмные волосы, casual)
3. Вставьте текст из `02-ozvuchka/golos-po-blokam.txt`
4. Экспорт клипов → вставьте в основной таймлайн вместо статичных avatar-*.png

### Способ C — Lip-sync через HeyGen / D-ID (максимально живо)
1. Загрузите `avatar-ref-front.png` как фото-аватар
2. Вставьте текст блоками из `golos-po-blokam.txt`
3. Русский голос: спокойный мужской, темп 0.95
4. Скачайте MP4 → импорт в CapCut
5. Чередуйте: 5–10 сек talking head → B-roll схема → снова talking head

**Рекомендация для старта:** A + чередование с B-roll (схемы из 01-kadry).
**Для роста канала:** перейти на C после 3–5 роликов.
