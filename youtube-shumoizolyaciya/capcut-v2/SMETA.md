# Смета: бюджетная шумоизоляция стены ~10 м²

> Ориентир для DIY, цены примерные (2025–2026, РФ). Пересчитайте под свой город.

## Площадь
- Стена: ~10 м² (например 3,5 × 2,8 м)
- С запасом на обрезку: +10–15%

## Материалы

| Позиция | Кол-во | Ориентир ₽ |
|---------|--------|------------|
| Профиль ПС 50×50 | ~20–25 м.п. | 3 000–4 500 |
| Профиль ПН 50×40 (направляющий) | ~8–10 м.п. | 1 200–1 800 |
| Минвата акустическая 50–80 кг/м³ (50 мм) | ~5–6 м² упаковки | 4 500–7 000 |
| ГКЛ 12,5 мм | ~11–12 листов | 5 500–7 500 |
| Демпферная лента | 2–3 рулона | 1 500–2 500 |
| Саморезы, дюбели, «гвозди» для профиля | комплект | 1 500–2 500 |
| Акустический герметик | 2–3 шт | 2 000–3 500 |
| Серпянка, грунт, шпаклёвка (финиш) | комплект | 2 500–4 000 |
| **Итого материалы** | | **~28 000–35 000** |

## Работа (если нанимаете)
| Позиция | Ориентир ₽ |
|---------|------------|
| Монтаж каркаса + ГКЛ, без финишной отделки | 15 000–25 000 |
| **Итого «под ключ»** | **~45 000–55 000** (впритык к 50к) |

## Где экономить МОЖНО
- Обычный ГКЛ вместо «акoustic board» (на первом слое)
- Демпферная лента вместо виброподвесов
- Одна стена вместо всей комнаты

## Где экономить НЕЛЬЗЯ
- Плотность и полнота укладки минваты
- Зазор каркаса от стены
- Акустический герметик по периметру
- Не покупать пенопластовые «акустические» панели на клей

## Бюджетный пирог (слои)
1. Бетон / панель
2. Демпферная лента
3. Каркас + зазор 2–3 см
4. Минвата 50 мм (плотная)
5. ГКЛ 12,5 мм × 1 слой
6. Герметик по периметру
