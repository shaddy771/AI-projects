# AGENTS.md

## Avito listings

При задачах про Авито, автозагрузку, объявления товаров, описания, картинки или XLSX/фиды:

1. Следуй skill `avito-agent/.cursor/skills/avito-listings/SKILL.md`
2. Читай конфиг `avito-agent/workspace/seller.yaml` (или `examples/seller-config.example.yaml`)
3. Сверяй колонки с официальным шаблоном категории: https://autoload.avito.ru/format/
4. Перед «готово» укажи пробелы из `avito-agent/checklists/full-placement.md`
5. Отвечай на языке пользователя (по умолчанию русский)
