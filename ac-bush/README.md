# FROSTBITE — бушующий сайт кондиционеров

Агрессивный лендинг для продажи кондиционеров. Два выбранных направления дизайна объединены в один поток:

1. **Heat vs Ice** — hero со слайдером «жара / холод»
2. **Typhoon Cool** — интерактивный блок с термометром 38° → 22°

## Идея

Летом кондиционер покупают не «посмотреть каталог», а **снять боль прямо сейчас**. Сайт давит жарой, обещает мгновенный холод и ведёт к одному действию — «Заморозить цену».

| Блок | Что делает |
| --- | --- |
| Heat alert | срочность: «+38°, монтаж сегодня» |
| Hero slider | контраст жары и прохлады одним жестом |
| Typhoon | кнопка «Включить холод», падает температура |
| Модели | три SKU без карточной сетки |
| Форма | короткий захват лида |

## Запуск

```bash
cd ac-bush
npm install
npm run dev
```

Откройте `http://localhost:5174`.

## Концепты (архив)

Все 4 исходных мокапа — в `public/concepts/`. В продакшн-версии реализованы **v1** и **v2**.

## Стек

- Vite + vanilla JS/CSS
- Парные фото hero в `public/hero-hot.png`, `public/hero-cold.png`
- CSS-анимация холодного потока в Typhoon-секции
