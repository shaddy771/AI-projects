# ЗамокСервис — Вскрытие замков в Могилёве и области

SEO-оптимизированный лендинг для услуг аварийного вскрытия замков.

## Структура

- `index.html` — главная страница (Могилёв)
- `bobruisk.html` — Бобруйск
- `gorki.html` — Горки
- `osipovichi.html` — Осиповичи
- `css/style.css` — стили
- `js/main.js` — формы, аналитика, UX
- `robots.txt`, `sitemap.xml` — SEO

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Настройка перед публикацией

1. Замените телефон `+375 (29) 123-45-67` на реальный
2. Обновите домен `vskrytie-zamkov-mogilev.by` в meta-тегах и sitemap
3. Подключите Яндекс.Метрику и Google Analytics в `index.html`
4. Добавьте реальное OG-изображение в `images/og-cover.jpg`
