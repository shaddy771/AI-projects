# SILENCIO — Before / After

Лендинг бренда шумоизоляции, где продукт объясняется не каталогом плит, а одним жестом: сдвинул линию — комната стала тише.

## Идея

Шумоизоляцию сложно «продать словами». Покупатель не чувствует ΔRw и NRC — он чувствует разницу между шумной и спокойной комнатой. Поэтому весь первый экран строится вокруг сравнения **До / После** в одном и том же пространстве.

Слайдер здесь не декоративный трюк, а главный аргумент:

- слева — привычный городской шум (холодный свет, беспокойная атмосфера);
- справа — та же планировка после акустической отделки (тёплый свет, ощущение покоя);
- в центре — жест пользователя, который сам «включает» тишину.

Бренд говорит не «купите панели», а «посмотрите, как комната затихает».

## Дизайн

### Первый экран = одна композиция

Hero занимает весь viewport и читается как единая сцена, а не как дашборд:

1. бренд **SILENCIO** как главный визуальный сигнал;
2. один короткий заголовок — «Тишина, которую видно»;
3. одно пояснение;
4. одна группа CTA;
5. одно доминантное изображение-сцена (комната), а не карточки товаров.

Никаких стат-полос, расписаний, бейджей и промо-стикеров поверх фото.

### Визуальный язык

| Элемент | Решение |
| --- | --- |
| Палитра | уголь / тёплый дуб / шалфей — спокойствие, не «техно-неон» |
| Шрифты | **Fraunces** (бренд и заголовки) + **Outfit** (интерфейс) |
| Фон ниже hero | мягкие градиенты и свет, без плоской заливки |
| До | холодный серо-голубой свет, город за окном |
| После | тёплые тона, панели как часть интерьера |

### Взаимодействие

- drag по сцене или за круглую ручку;
- скрытый `range` для доступности с клавиатуры;
- короткая intro-анимация: ползунок сам чуть сдвигается от «шума» к балансу;
- подсказка «Тяните» в углу hero.

Ниже hero — только необходимые блоки, у каждого одна задача:

- **Как это работает** — объяснить жест сравнения;
- **Системы** — три уровня тишины без карточной сетки;
- **Расчёт** — короткий путь к заявке.

## Почему этот формат

Из вариантов «сайта через 5–10 лет» выбран **Before / After Sound**, потому что его реально собрать сегодня:

- без VR и тяжёлого 3D;
- с понятной конверсией («увидеть разницу» → расчёт);
- с сильным эмоциональным контрастом, который каталог материалов обычно теряет.

Это мост между витриной и будущим «пространственным» шопингом: пользователь уже не листает SKU, а сравнивает состояния комнаты.

## Стек

- Vite
- Vanilla JS + CSS
- Парные фото одной комнаты в `public/`

Зависимостей почти нет — акцент на идее и ощущении, а не на фреймворке.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173` и потяните центральную линию на hero.

Сборка:

```bash
npm run build
npm run preview
```

## Структура

```
public/           # room-before.png, room-after.png
src/
  app.js          # разметка, слайдер, форма, reveal
  style.css       # дизайн-система и анимации
  main.js         # точка входа
index.html
```

## Что можно развить дальше

- звук: тихий ambient усиливается к стороне «После»;
- квиз по источнику шума прямо из положения слайдера;
- подстановка фото комнаты клиента (до) и генерация/рендер «после»;
- расчёт сметы по выбранной системе сразу под hero.
