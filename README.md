# ТИШЬ — интерактивный hero шумоизоляции

Демонстрационный главный блок сайта по продаже и установке шумоизоляции.

## Возможности

- 3D-стена в разрезе на Three.js
- Сборка / разборка слоёв слайдером и кнопками
- Автопоказ конструкции
- Подписи слоёв и счётчик снижения шума в дБ
- Вращение сцены мышью / тачем

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```
