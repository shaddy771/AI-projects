# Референс: Orbital Dial — «Крути — и комната слушается»

**Бренд:** AERO  
**Концепт:** #2 из футуристичных направлений (`ac-bush/public/concepts-future/ac-future-v2-orbital.png`)  
**Сборка:** `aero-orbital/`  
**Год ощущения:** ~2034  
**Тип:** минималистичный премиум-лендинг кондиционеров

---

## 1. Суть в одном предложении

Сайт — не каталог. Сайт — **одна крутилка климата**: пользователь задаёт температуру, и вся страница «слушается» — меняет оттенок, статусы и подсказки.

---

## 2. Продуктовая идея

| Было (обычный магазин) | Стало (Orbital Dial) |
| --- | --- |
| 12 карточек SKU | одно кольцо 16–30°C |
| фильтры BTU / площадь | температура как главный жест |
| статичный тёмный фон | живая атмосфера: холод ↔ тепло |
| CTA «Купить» | CTA «Подобрать AERO» под выбранный климат |

**Обещание бренда:** климат настраивается жестом, без лишнего интерфейса.

**Главный слоган:** «Крути — и комната слушается»

**Правила hero**
- крутилка — визуальный и интерактивный центр viewport;
- бренд AERO — в шапке; заголовок и lede — над dial, по центру;
- диапазоны температур — тонкой строкой под dial;
- три meta-поля — внизу hero, узкой колонкой;
- без бейджей, стат-полос, промо-стикеров и боковой двухколоночной вёрстки.

---

## 4. Главный интерактив: центральная крутилка

### Поведение
- управление **центром** (кноб), не ручкой на краю кольца;
- drag по кругу → температура 16…30°C (шаг 1°);
- колёсико мыши над dial → ±1°;
- intro: кольцо само «приходит» от ~28° к 22° (зона комфорта);
- отметка комфорта (22°) на орбите — тихая точка.

### Визуал крутилки
- круглая ручка с насечками и меткой-«риской»;
- внутри — крупная температура + `°C`;
- снаружи — SVG-дуга прогресса;
- статус под dial: Прохладно / Комфорт / Тепло / Жарко.

### Диапазоны настроения

| °C | Статус | Смысл для UX |
| --- | --- | --- |
| 16–19 | Прохладно | быстрое охлаждение, выше мощность |
| 20–23 | Комфорт | целевая зона, «выбор» линейки |
| 24–26 | Тепло | мягкий климат |
| 27–30 | Жарко | тёплая атмосфера страницы |

## 5. Глобальная тема сайта (ключ сборки)

При вращении крутилки меняются **не только dial**, а **весь сайт**.

### Градиент оттенков
- **Холод (16°):** тускло-синий фон, холодный акцент, чуть голубоватый текст  
- **Комфорт (~22°):** нейтрально-прохладный переход  
- **Тепло (30°):** тускло-оранжевый фон, тёплый акцент, кремовый ink

### Что перекрашивается
- `--bg`, `--bg-soft` — фон страницы  
- `--accent`, `--accent-deep` — статусы, активные линии, бейджи  
- `--ink`, `--ink-soft` — текст  
- `--glow` — ambient-свечение  
- `--line` — разделители и бордеры  
- карточки, форма, футер, подсветка активного пункта списка

### Ощущение
Не неон и не «киберпанк». Тусклые, приглушённые тона — как свет в комнате, а не как UI-скин.

**Формула:** `ratio = (temp − 16) / (30 − 16)` → линейная интерполяция RGB.

## 6. Визуальный язык

| Параметр | Значение |
| --- | --- |
| Настроение | спокойный tech-ритуал, spa × прибор |
| Фон | тёмный, дышит цветом температуры |
| Display | Instrument Serif (заголовки, °C) |
| Body | Inter (навигация, meta, форма) |
| Акцент | не фиксированный цвет — **следует температуре** |
| Радиусы | мягкие 8–16px, крутилка — идеальный круг |
| Свет | soft glow вокруг dial, без резких бликов |
| Избегать | фиолетовый неон, агрессивные sale-баннеры, сетка карточек в hero |

### Референс-ощущения (не копировать 1:1)
- термостат Nest / Ecobee — ритуал кручения;
- Apple Vision spatial UI — воздух и минимум хрома;
- премиум HVAC-сайты — тишина и материал, не «распродажа».

1. **Hero / Dial** — крутилка + копирайт + meta  
2. **Линейка** — три модели списком (S9 / S12 / S18), без карточной сетки  
3. **Подбор** — форма: телефон + тип комнаты + CTA «Подобрать AERO»  
4. **Footer** — AERO · «Климат · без лишнего интерфейса»

Форма подставляет выбранную температуру в текст:  
«подберёт AERO под выбранную температуру **22**°C».

## 8. Копирайт (канон)

- Eyebrow: `Orbital · 2034`
- H1: `Крути — и комната слушается`
- Lede: орбитальный интерфейс комфорта; одно кольцо вместо десяти экранов

Тон: спокойный, уверенный, без «жара сгорит» и без крика скидок.

## 9. UX-правила

1. **Один жест = одно понимание.** Крутишь — становится холоднее/теплее и визуально, и по цифре.  
2. **Тема глобальна.** Если фон не меняется — эффект «комната слушается» ломается.  
3. **Мало UI.** Не добавлять второй контрол температуры рядом.  
4. **Доступность:** aria-label на крутилке; статусы через live-текст; `prefers-reduced-motion` отключает intro/переходы.  
5. **Mobile:** dial остаётся в центре под заголовком; крутилка ≥ ~150px hit-area; drag и колёсико работают.

## 10. Технический референс сборки

| Часть | Реализация |
| --- | --- |
| Стек | Vite + vanilla JS/CSS |
| Dial | SVG-дуга + центральный knob (`src/orbital.js`) |
| Тема | `applyTemperatureTheme(ratio)` → CSS variables на `:root` |
| Ambient | fixed слой `.ambient` + `--glow` |
| Порт | `5175` |
| Запуск | `cd aero-orbital && npm install && npm run dev` |

## 11. Что можно развить дальше (вне текущего MVP)

- haptic / лёгкий звук щелчка по градусу;
- сохранение выбранной °C в URL (`?t=22`);
- подстановка фото комнаты клиента под dial;
- AR-превью «как выглядит блок AERO на стене» после выбора температуры.

---

## 12. Критерий готовности

Сборка соответствует референсу, если:

- [ ] управление — **центральная крутилка**;
- [ ] температура 16–30 видна крупно внутри;
- [ ] при холодной температуре сайт **тускло-синий**;
- [ ] при тёплой — **тускло-оранжевый**;
- [ ] переход плавный, без скачков палитры;
- [ ] hero без товарной сетки;
- [ ] слоган и тон совпадают с разделом 8.
