# AERO — Orbital Dial

Минималистичный лендинг кондиционеров «из будущего». Вместо каталога — **орбитальное кольцо комфорта**: крутишь, температура меняется, атмосфера страницы откликается.

Концепт **#2** из `ac-bush/public/concepts-future/`.

## Идея

- одно кольцо 16–30°C вместо десятка экранов;
- продукт — «камень» в центре;
- фон и подсказки реагируют на выбранный режим (прохладно / комфорт / тепло);
- метаданные (мощность, площадь) пересчитываются от температуры.

## Запуск

```bash
cd aero-orbital
npm install
npm run dev
```

Откройте `http://localhost:5175` и проведите по кольцу.

## Стек

- Vite + vanilla JS
- SVG-дуга + pointer drag
- CSS ambient gradient
