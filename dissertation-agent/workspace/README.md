# Рабочая папка диссертации

Сюда клади материалы конкретной работы:

```text
workspace/
  project.yaml      # конфиг (скопируй из examples/)
  drafts/           # главы и разделы
  notes/            # тезисы, выписки, комментарии научрука
  sources/          # библиография, PDF-метаданные, заметки по источникам
```

Агент читает `project.yaml` и файлы в `drafts/` / `notes/`, затем пишет и правит текст по skill `dissertation-writer`.

Не коммить персональные данные и закрытые материалы, если репозиторий публичный.
