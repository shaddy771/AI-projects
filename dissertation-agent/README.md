# Диссертационный писательский агент

Агент для Cursor: помогает **писать, дорабатывать и редактировать** диссертацию (кандидатскую, докторскую, PhD) — по главам, со стилем, логикой и литературой.

## Что умеет

- Собрать план и структуру работы
- Написать черновик введения, глав, заключения
- Отредактировать академический стиль и связность
- Проверить согласованность цели, задач, новизны и положений на защиту
- Помочь с оформлением списка литературы (без выдуманных источников)

## Быстрый старт

1. Открой этот репозиторий в Cursor (Agent / Cloud Agent).
2. Скопируй конфиг:

```bash
cp dissertation-agent/examples/project-config.example.yaml \
   dissertation-agent/workspace/project.yaml
```

3. Заполни тему, задачи, положения на защиту и пути к черновикам.
4. Положи материалы в `dissertation-agent/workspace/` (`drafts/`, `notes/`, `sources/`).
5. Напиши агенту, например:

```text
Отредактируй главу 1 в academic style и проверь согласованность с целью из project.yaml
```

или используй готовые промпты из `prompts/`.

## Структура проекта

```text
dissertation-agent/
  .cursor/skills/dissertation-writer/   # skill агента
  .cursor/rules/                        # правила для Cursor
  templates/                            # шаблоны введения, глав, заключения
  prompts/                              # готовые режимы запросов
  checklists/                           # редактура и готовность к защите
  examples/                             # пример project.yaml
  workspace/                            # твоя рабочая диссертация
```

## Режимы работы

| Режим | Как вызвать |
|---|---|
| Написать раздел | `prompts/write-chapter.md` |
| Править стиль | `prompts/edit-style.md` |
| Проверить логику | `prompts/check-consistency.md` |
| Литература | `prompts/expand-literature.md` |

## Принципы

1. Работа идёт **по разделам**, не «вся диссертация одним файлом».
2. Источники и данные **не выдумываются**; пробелы помечаются явно.
3. Автор несёт ответственность за научную достоверность, оригинальность и требования совета/вуза.
4. Локальные правила из `workspace/project.yaml` важнее общих шаблонов.

## Пример запроса

```text
Режим: написать
Раздел: Глава 1, пункт 1.2
Тема: из project.yaml
Исходные тезисы: см. workspace/notes/
Объём: 8–10 страниц
Стиль ссылок: ГОСТ
Не выдумывать источники. В конце — выводы и список пробелов.
```

## Дальше

После заполнения `project.yaml` можно сразу просить агента:

1. собрать план по `templates/structure.md`;
2. написать введение;
3. пройтись по главам;
4. прогнать `checklists/editorial.md` и `checklists/defense-readiness.md`.
