# Редакторский чеклист

Отмечай пункты при каждой крупной правке раздела.

## Смысл и структура

- [ ] У раздела одна ясная цель
- [ ] Логика абзацев последовательна
- [ ] Есть промежуточные и итоговые выводы
- [ ] Нет дублирования соседних разделов

## Научный аппарат

- [ ] Цель/задачи/положения согласованы с текстом
- [ ] Утверждения опираются на источники или данные
- [ ] Разведены обзор, метод, результат, интерпретация
- [ ] Ограничения исследования названы явно (где уместно)

## Язык и стиль

- [ ] Термины единообразны
- [ ] Нет разговорности и публицистики
- [ ] Нет канцелярита и «воды»
- [ ] Предложения читаемы, без перегруза

## Оформление

- [ ] Нумерация разделов корректна
- [ ] Ссылки в тексте соответствуют списку литературы
- [ ] Таблицы/рисунки подписаны и упомянуты в тексте
- [ ] Объём в рамках плана

## Финал раздела

- [ ] Выводы отвечают на задачу раздела
- [ ] Пометки `[ТРЕБУЕТСЯ …]` закрыты или явно перечислены автору
