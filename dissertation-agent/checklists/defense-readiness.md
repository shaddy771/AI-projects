# Чеклист готовности к защите (черновик текста)

## Введение

- [ ] Актуальность обоснована
- [ ] Объект/предмет разведены
- [ ] Цель и задачи согласованы
- [ ] Новизна сформулирована пунктами
- [ ] Положения на защиту проверяемы и опираются на главы

## Основная часть

- [ ] Каждая задача закрыта содержанием глав
- [ ] Методы описаны воспроизводимо
- [ ] Результаты отделены от обсуждения (где применимо)
- [ ] Выводы по главам не повторяют текст дословно, а фиксируют итог

## Заключение и аппарат

- [ ] Выводы соответствуют задачам
- [ ] Положения на защиту подтверждены
- [ ] Ограничения и перспективы указаны
- [ ] Список литературы полный и согласованный со ссылками
- [ ] Приложения (если нужны) связаны с основным текстом

## Формальные требования совета/вуза

- [ ] Объём и структура по локальным правилам
- [ ] Оформление ссылок по требуемому стандарту
- [ ] Публикации/апробация отражены корректно (без преувеличений)
