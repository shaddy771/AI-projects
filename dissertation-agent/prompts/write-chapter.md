# Промпт: написать главу / раздел

Скопируй и заполни, затем отправь агенту.

```text
Режим: написать
Раздел: Глава X / пункт X.Y
Тема диссертации: …
Цель раздела: …
Связь с задачей №… и положением на защиту №…
Исходные материалы (тезисы, данные, источники):
- …
Ограничения:
- объём: … стр. / … знаков
- стиль ссылок: ГОСТ / APA / …
- нельзя выдумывать данные и источники
Требования к выдаче:
1) краткий план раздела
2) текст раздела
3) выводы по разделу
4) список пробелов и нужных источников
```
