# Промпт: импорт частичной диссертации из DOCX

```text
Режим: импорт DOCX
Файл: [путь к .docx или вложение]
Задача:
1) сконвертировать в Markdown в workspace/drafts/
2) по возможности разбить на введение / главы / заключение
3) кратко описать, что уже готово и что дописать
4) предложить следующий шаг правки (стиль / логика / конкретный раздел)
Нельзя выдумывать недостающие главы и источники.
```

Локально или через агента:

```bash
pip install -r dissertation-agent/requirements.txt
python dissertation-agent/tools/import_docx.py путь/к/файлу.docx --split
```
