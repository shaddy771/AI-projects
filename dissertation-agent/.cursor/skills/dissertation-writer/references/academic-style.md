# Академический стиль для диссертации

## Принципы

1. **Точность** — термины однозначны и согласованы по всей работе.
2. **Доказательность** — утверждение подкреплено ссылкой, данными или явным рассуждением.
3. **Нейтральность** — без публицистики, оценочных клише и разговорности.
4. **Экономия** — убрать воду, повторы и риторические вопросы без функции.

## Предпочитать

- «В работе показано / установлено / обосновано…»
- «Согласно [1], …; вместе с тем [2] указывает…»
- «Результаты свидетельствуют о…»
- «Ограничением исследования является…»

## Избегать

- «Все знают, что…», «очевидно, что…» без основания
- «Хочется отметить», «нельзя не сказать»
- Канцелярит: «осуществление реализации», «в целях обеспечения»
- Абсолюты: «единственно верный», «полностью решает проблему»
- Англицизмы без нужды, если есть устойчивый русский термин

## Структура абзаца

1. Тезис абзаца.
2. Обоснование / данные / ссылка.
3. Вывод или переход к следующему шагу рассуждения.

## Редактирование «сырого» текста

При стилистической правке:

1. Сохрани смысл и авторские акценты.
2. Унифицируй термины.
3. Разбей перегруженные предложения.
4. Вынеси повторы в одну формулировку.
5. Отметь места без источника маркером `[ТРЕБУЕТСЯ ИСТОЧНИК]`.
