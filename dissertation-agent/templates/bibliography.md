# Список литературы (шаблон, ГОСТ-ориентир)

Правила:

1. Нумерация по порядку упоминания **или** алфавиту — как задано в `project.yaml`.
2. Не добавляй источники, которых нет в тексте (и наоборот).
3. Для каждого пункта сохраняй: авторы, название, выходные данные, DOI/URL при наличии.
4. Пометки `[НЕПРОВЕРЕНО]` ставь, если библиоданные не подтверждены.

## Пример оформления (ориентир)

1. Иванов И. И. Название монографии. — М.: Издательство, 2020. — 256 с.
2. Петров П. П., Сидоров С. С. Название статьи // Название журнала. — 2021. — Т. 12, № 3. — С. 45–60.
3. Title of the paper / J. Smith et al. // Journal Name. — 2019. — Vol. 10, No. 2. — P. 100–118. — DOI: …
