# Полное размещение объявлений на Авито — чеклист

Агент готовит **описания, фото-ссылки и XLSX**. Этого недостаточно для публикации:
нужен кабинет, тариф/подписка и корректная автозагрузка.

Официально: [Автозагрузка Авито](https://www.avito.ru/business/tools/autoload),
[инструкция и шаблоны](https://autoload.avito.ru/format/).

## 1. Аккаунт и доступ к автозагрузке

- [ ] Профиль типа **компания** (не частное лицо)
- [ ] Реквизиты компании подтверждены (для части категорий / инструментов)
- [ ] Подключён **тариф / профессиональный план**
- [ ] Для категории «Товары» — подписка на инструменты **Расширенная** или **Максимальная**
- [ ] В меню кабинета виден раздел **Автозагрузка**
- [ ] На кошельке достаточно средств / пакетов размещения под число строк в файле

## 2. Шаблон категории (критично)

- [ ] Скачан **актуальный** шаблон именно вашей категории из «Правила и шаблоны»
- [ ] Колонки из `avito_listings.xlsx` **сверены** с шаблоном (агент даёт базовый набор + extras)
- [ ] Заполнены **обязательные** параметры категории (GoodsType, ProductType, бренд, размер и т.д.)
- [ ] Значения из выпадающих списков шаблона — без самодельных формулировок

> Поля категории периодически меняются. Источник истины — шаблон в кабинете, не этот репозиторий.

## 3. Содержимое объявления

- [ ] Стабильный уникальный `Id` (не менять между выгрузками)
- [ ] `AvitoId` пустой для новых; не копировать при размножении на города
- [ ] `Title` ≤ ~50 символов, без спама и капса
- [ ] `Description` по правилам (допустимый HTML: p, br, strong, ul, li, …)
- [ ] `Price` — целое число рублей без пробелов и «₽»
- [ ] `Address` — полный адрес как в справочнике Авито
- [ ] Телефон и способ связи корректны
- [ ] `AdType` / `Condition` / `Availability` заполнены допустимыми значениями
- [ ] Товар не из запрещённых категорий / без нарушений правил площадки

## 4. Фото и медиа

- [ ] Прямые публичные URL в `ImageUrls` (открываются без логина) **или**
- [ ] `ImageNames` + zip-архив фото вместе с файлом (суммарно ≤ 100 МБ)
- [ ] Фото соответствуют товару, без чужих водяных знаков и стоковой «обманки» при продаже б/у
- [ ] Достаточно ракурсов (обычно 3–10); первое фото — самое продающее
- [ ] Видео (если есть) — RuTube / VK Видео в `VideoURL`

## 5. Загрузка и публикация

- [ ] Файл загружен вручную **или** выложен по HTTPS-ссылке для расписания автозагрузки
- [ ] Расписание обращений к фиду настроено (это не время публикации!)
- [ ] Лимит «объявлений за период» ≥ числу новых/обновляемых строк
- [ ] Первая выгрузка — на 10–20 позициях, не на всём каталоге
- [ ] Просмотрен **отчёт автозагрузки**
- [ ] Отклонённые модерацией объявления исправлены в файле и перезагружены

## 6. Что агент НЕ делает (нужно отдельно)

| Задача | Как закрыть |
|---|---|
| Оплата тарифа / подписки | Кабинет Авито |
| Юр. проверка / ИНН (Работа и др.) | Кабинет Авито |
| Точный категорийный XLSX со всеми enum-полями | Скачать шаблон категории и дополнить `extras` |
| Хостинг фото с постоянными URL | CDN, Яндекс Диск (по инструкции Авито), свой сервер |
| Автоматический pull фида по расписанию | Публичный URL файла + настройка в Автозагрузке |
| Ответы покупателям, чаты, статистика | Кабинет / [API Авито](https://developers.avito.ru/) |
| Продвижение (XL, выделение, Promo*) | Параметры в шаблоне + бюджет |
| Соблюдение законов о маркировке / чеках | На стороне продавца |

## 7. Быстрый путь после генерации агентом

1. `avito-agent generate ...` → получить XLSX  
2. Открыть шаблон категории из кабинета и **дописать** недостающие обязательные колонки  
3. Проверить, что все `ImageUrls` открываются в браузере инкогнито  
4. Загрузить 5–10 строк → разобрать отчёт → править массово  
5. Подключить постоянный URL фида, если каталог обновляется часто
