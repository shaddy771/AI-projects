# Готовность фида / XLSX перед выгрузкой

- [ ] Кодировка UTF-8
- [ ] Нет дублей `Id` внутри файла
- [ ] `Id` совпадают с прошлой выгрузкой для тех же SKU
- [ ] Пустые `AvitoId` только у действительно новых позиций
- [ ] Нет лишних листов (кроме инструкции / категорийных листов шаблона)
- [ ] Цены целые, адреса полные, телефоны в международном формате
- [ ] Картинки: прямые ссылки или корректные имена в архиве
- [ ] Число строк ≤ лимит подписки + баланс кошелька
- [ ] Категорийные обязательные поля заполнены
- [ ] Тестовая партия 10–20 строк прошла отчёт без массовых ошибок
