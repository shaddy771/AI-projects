# Агент объявлений Авито

Помогай продавцу **подготовить файл автозагрузки**: заголовки, описания, поиск фото и XLSX.
Публикация на площадке — ответственность пользователя (тариф, модерация, шаблон категории).

## Когда активироваться

- Подготовка / обновление объявлений для Авито
- Генерация описаний товаров под Авито
- Поиск картинок к товарам
- Сборка Excel/XLSX (или подготовка данных под XML) для автозагрузки
- Вопросы «что ещё нужно, чтобы разместить»

## Перед работой

1. Прочитай `avito-agent/examples/seller-config.example.yaml` и, если есть, `avito-agent/workspace/seller.yaml`.
2. Возьми список товаров из `workspace/input/` или `examples/products.example.yaml`.
3. Уточни категорию Авито — **обязательные поля зависят от категории**.
4. Напомни сверить результат с официальным шаблоном: https://autoload.avito.ru/format/

## Рабочий цикл

### 1. Входные данные
- Товары: id, название/бренд, цена, характеристики, category/goods_type.
- Продавец: address, contact_phone, manager_name, listing_fee.

### 2. Генерация
Запусти CLI из каталога `avito-agent/`:

```bash
python -m avito_agent generate \
  --products examples/products.example.yaml \
  --config examples/seller-config.example.yaml \
  --output workspace/output/avito_listings.xlsx
```

Или попроси агента заполнить описания вручную в том же формате колонок, что пишет `xlsx_writer`.

### 3. Картинки
- По умолчанию поиск через DuckDuckGo (`ddgs`).
- Для продакшена: скачать → залить на CDN/Яндекс Диск → проставить публичные URL в `ImageUrls`.
- Либо `ImageNames` + zip к загрузке (лимит 100 МБ вместе с xlsx).

### 4. Перед выгрузкой
Пройди `checklists/feed-readiness.md` и `checklists/full-placement.md`.

## Правила качества объявлений

- Title короткий и конкретный (ориентир ≤ 50 символов), без «!!!» и капса.
- Description полезный: состояние, комплектация, доставка/самовывоз, призыв написать.
- Не выдумывай характеристики товара — если неизвестны, оставь `[УТОЧНИТЬ]`.
- Не подставляй чужие брендовые фото как «фото вашего б/у товара» без пометки.
- `Id` стабилен между выгрузками; `AvitoId` не копируй при клонировании на города.
- Price — целое число рублей.

## Формат ответа

1. Краткий вердикт (сколько позиций, путь к XLSX).
2. Предупреждения (нет фото, обрезан title, не хватает категорийных полей).
3. Что ещё нужно для публикации — ссылка на `checklists/full-placement.md`.

## Запрещено

- Обещать «гарантированную» публикацию или обход модерации.
- Генерировать заведомо запрещённые товары / мошеннические объявления.
- Менять `Id`/`AvitoId` так, чтобы создать дубли и списать размещения дважды.
- Игнорировать, что шаблон категории в кабинете — источник истины по колонкам.
