# Типовая структура диссертации (ориентир ВАК РФ)

Используй как базовый каркас. Если в `project.yaml` задана структура вуза/совета — она приоритетнее.

## Кандидатская / докторская (общая схема)

1. **Титульный лист**
2. **Оглавление**
3. **Введение**
   - актуальность темы;
   - степень разработанности;
   - объект и предмет;
   - цель и задачи;
   - методология и методы;
   - научная новизна;
   - теоретическая и практическая значимость;
   - положения, выносимые на защиту;
   - апробация / публикации;
   - структура работы.
4. **Глава 1. Теоретико-методологические основы / обзор**
5. **Глава 2. Метод, эмпирика, модель, дизайн исследования**
6. **Глава 3(+). Результаты, анализ, обсуждение**
7. **Заключение** (выводы по задачам, перспективы)
8. **Список литературы**
9. **Приложения** (при необходимости)

## Рекомендации по объёму (ориентиры)

Конкретные нормы зависят от специальности и совета. Если в конфиге не задано:

| Часть | Ориентир |
|---|---|
| Введение | 8–15 стр. |
| Глава | 30–60+ стр. (по числу глав) |
| Заключение | 5–10 стр. |
| Литература | полнота по теме, не «для объёма» |

## Связка обязательных элементов

```
Проблема → Цель → Задачи → Методы → Результаты → Выводы
                ↘ Новизна → Положения на защиту ↗
```

Каждая задача должна иметь след в результатах и заключении. Каждое положение на защиту — опору в главах.
